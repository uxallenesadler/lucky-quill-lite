# lucky-quill-lite

Product designer · Framer and prototyping · building tiny tools

日常脚本的集中地

## 用法

```bash
cat data.txt | cargo run
```

输出：

```
   3  error: timeout
   1  warn: retry
---
2 unique / 4 lines
```

## 安装

```bash
git clone https://github.com/USER/lucky-quill-lite.git
cd lucky-quill-lite
cargo build --release
```
